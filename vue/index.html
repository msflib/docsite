    MSF Vue¶

    This repository contains the MSF Vue package and its companion frontend tooling. It is meant to provide a reusable UI layer built with Vue, shared styling, and component patterns for downstream projects within the broader MSF ecosystem.

    Package purpose¶

    The library is intended to provide:

    • Vue-based reusable component primitives
    • support for styling and integration with a modern frontend stack
    • a shared component story for downstream app work
    • a consistent library package for MSF frontend use cases
