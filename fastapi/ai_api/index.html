    AI API Module¶

    The AI API module exposes user-facing routes for search, Q&A, and agent-style workflow interactions built on the shared AI Core runtime.

    What it provides¶

    • Search endpoint for retrieval over configured vector stores
    • Ask endpoint for retrieval-augmented responses
    • Agent status and agent ask endpoints
    • Response protocol support for different client expectations
    • Scoped routing based on account and workspace context

    Installation¶

    [tool.poetry.dependencies]
msflib = { git = "https://github.com/msflib/fastapi.git", subdirectory = "core", rev = "dev" }
msflib-ai-api = { git = "https://github.com/msflib/fastapi.git", subdirectory = "modules/ai_api", rev = "dev" }

    Example: mount the router¶

    from fastapi import FastAPI
from msflib.ai_api.router import router as ai_router

app = FastAPI()
app.include_router(ai_router(prefix="/api/v1/ai"))

    Public API surface¶

    Name Signature Params Returns Description
    router router(...) session, account/workspace deps, settings FastAPI router Main AI transport routes
    create_llm_router create_llm_router(...) model and deps router Creates routable LLM ask endpoints
    create_agent_router create_agent_router(...) agent config and deps router Creates agent-aware ask endpoints

    Routes¶

    • POST /ai/search — retrieval and hit lookup
    • POST /ai/ask — grounded answer generation
    • GET /ai/status — service status
    • GET /ai/protocols — supported response protocols
    • GET /ai/agent/status — agent runtime status
    • POST /ai/agent/ask — agent-based question answering
    • POST /ai/agent/ask/stream — streaming agent response

    Request examples¶

    Search¶

    POST /api/v1/ai/search
Content-Type: application/json

{
  "query": "replace retrieval",
  "k": 3
}

    Ask¶

    POST /api/v1/ai/ask
Content-Type: application/json

{
  "question": "What does the latest content mention?",
  "k": 2
}

    Protocol handling¶

    The ask endpoint supports response protocols such as the default native protocol or OpenAI-style envelopes. The X-AI-Protocol header can override the default when needed.

    Troubleshooting¶

    • Requests without workspace context may fail validation when workspace-scoped retrieval is required.
    • Unsupported protocols return a client error.
    • Provider selection depends on the underlying AI Core registry and task binding configuration.
