    Known pitfalls¶

    Problems that have already cost debugging time. Each entry gives the symptom, the cause and the fix.

    Relationship and PEP 563¶

    Symptom: InvalidRequestError: ... failed to locate a name ('X | None') on the first instantiation of a model, not at import or create_all().

    Cause: from __future__ import annotations turns the annotation into a string that SQLAlchemy's class registry can't resolve.

    Fix: follow MDL-9: no future import in that file, quoted forward references. create_all() passing does not prove the mapping works.

    SQLite savepoints do not roll back¶

    Symptom: after session.begin_nested() and a later session.rollback(), the row is still there.

    Cause: pysqlite's own transaction handling commits the savepoint.

    Fix: wrap the engine with core's helper, which installs the workaround once (TST-2):

    from msflib.db.sqlite import enable_savepoints

engine = enable_savepoints(
    create_engine("sqlite://", connect_args={"check_same_thread": False}, poolclass=StaticPool)
)

    Don't hand-write the pysqlite event listeners in a fixture.

    Tables defined twice¶

    Symptom: Table '...' is already defined for this MetaData instance.

    Cause: a module __init__.py imports models eagerly, and the namespace package is loaded through two sys.path entries.

    Fix: MOD-2.

    Tests run old code¶

    Symptom: a change has no effect in tests, or an import that exists in the source is missing.

    Cause: a non-editable copy in site-packages shadows the workspace.

    Fix: see Stale installed copies.

    Relationship access after commit¶

    Symptom: DetachedInstanceError when reading a relationship on a row that a committing action (for example delete_by_all) already returned.

    Fix: use a row you already hold in the request context instead of the detached row's relationship.

    Recursive default construction¶

    Symptom: RecursionError when constructing an action or service.

    Cause: x or XAction() defaults in __init__ that construct back to the original class.

    Fix: SVC-7.

    HookRegistry.bind() does not register listeners¶

    Symptom: a listener registered in __init__ never fires.

    Cause: bind() only records the binding so it can be replaced later.

    Fix: call emitter.on(...) (or use @emitter.listen) and then bind(). See workspaces/eventbus/__init__.py.

    Missing-package tests stop covering the probe¶

    Symptom: after moving to is_importable, a "package missing" test crashes during loading instead of skipping.

    Fix: TST-7: patch is_importable consistently with the faked import.
