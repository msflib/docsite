    MSFLib Payments Module¶

    The Payments module is integral to handling various aspects of payment processing, including initiation, verification through gateways, and queue-driven post-payment processing.

    What This Module Provides¶

    • Unified PaymentProcessor: Supports integration with multiple payment gateways such as Stripe and Paystack.
    • Persistence: Manages the state of payments and payment-queue information.
    • Verification Endpoints: Ensures proper payment confirmation and handling.
    • Event Emission: Enables downstream processing once payment events occur.

    Installation¶

    For Pydantic v2 (recommended)¶

    Add the following to your pyproject.toml:

    [tool.poetry.dependencies]
msflib = { git = "https://github.com/msflib/fastapi.git", subdirectory = "core", rev = "dev" }
msflib-payments = { git = "https://github.com/msflib/fastapi.git", subdirectory = "modules/payments", rev = "dev" }

    For Pydantic v1 (legacy)¶

    [tool.poetry.dependencies]
pydantic = "^1.10"
pydantic-settings = "^1.10"

msflib = { git = "https://github.com/msflib/fastapi.git", subdirectory = "core", rev = "core-v0.1.1" }
msflib-payments = { git = "https://github.com/msflib/fastapi.git", subdirectory = "modules/payments", rev = "payments-v0.1.0" }

    Refer to Pydantic Version Compatibility for migration guidance.

    Quick Start¶

    1) Mount Routes¶

    To integrate the payments router into a FastAPI application:

    from fastapi import FastAPI
from msflib.payments.router import router as payments_router

app = FastAPI()
app.include_router(
    payments_router(
        get_session=get_session,
        get_current_account=get_current_account,
        settings=settings,
        prefix="/payments",
    )
)

    2) Initiate Payments¶

    Trigger payment processing within your business logic:

    from msflib.payments.models import PaymentData
from msflib.payments.service.processor import process_payment

payment = await process_payment(
    session=session,
    payment_data=PaymentData(
        amount=5000,
        description="Subscription",
        gateway="paystack",
    ),
    account=current_account,
    settings=settings,
    queue_event_key="subscription-create",
    queue_data={"plan": "pro"},
)

    API Surface (/payments)¶

    • GET /verify/{reference}: Verify payment and execute associated queue event.
    • GET /{payment_id}: Retrieve details of a specific payment associated with the current account.

    Main Programmatic APIs¶

    • PaymentProcessor(settings): Core processor component.
    • .gateway(gateway): Set the payment gateway.
    • await .initiate(account, payment_data): Initiate a payment transaction.
    • await .verify(reference): Verify payment using a reference ID.
    • process_payment(...): Comprehensive payment processing function.

    Models and Enums¶

    Definitions provided in msflib.payments.models:

    • Payment, PaymentCreate, PaymentRead, PaymentInfo
    • PaymentQueue, PaymentQueueCreate, PaymentQueueRead
    • PaymentGateway: Enum options include stripe, paystack.
    • PaymentStatus: Includes states like verified, unverified, failed, fulfilled.
    • PaymentQueueStatus: States include queued, processed.

    Configurations¶

    Settings related to Payments are retrieved using settings.scope("PAYMENTS"), particularly the PAYMENT_GATEWAY configuration.

    This detailed documentation should aid in understanding and utilizing the Payments module within the MSFLib library. The module facilitates diverse payment operations through a robust API and flexible integration capabilities.
