    AI Core Module¶

    The AI Core module provides the shared infrastructure for LLM, embeddings, vector search, provider registry, and prompt/tool orchestration across MSFLib services.

    What it provides¶

    • Unified LLM and embeddings factories
    • Provider registry abstractions for many LangChain backends
    • Vector store abstractions and scoped retrieval helpers
    • Request rate limiting and usage tracking
    • Long-term memory and checkpoint support for agent workflows
    • Tool factories for calculators, search, and retrieval helpers

    Installation¶

    [tool.poetry.dependencies]
msflib = { git = "https://github.com/msflib/fastapi.git", subdirectory = "core", rev = "dev" }
msflib-ai-core = { git = "https://github.com/msflib/fastapi.git", subdirectory = "modules/ai_core", rev = "dev" }

    Optional provider extras can be added later depending on your LLM stack.

    Example: create an LLM and embedding model¶

    from msflib.ai_core.config import AICoreSettings
from msflib.ai_core.providers import get_llm, get_embeddings

settings = AICoreSettings(
    LLM_PROVIDER="openai",
    LLM_MODEL="gpt-4o-mini",
    LLM_API_KEY="sk-...",
    EMBEDDING_PROVIDER="openai",
    EMBEDDING_MODEL="text-embedding-3-small",
    EMBEDDING_API_KEY="sk-...",
)

llm = get_llm(settings)
embeddings = get_embeddings(settings)

    Public API surface¶

    Name Signature Params Returns Description
    get_llm get_llm(settings) AI core settings LLM instance Builds a configured chat model
    get_embeddings get_embeddings(settings) AI core settings embedding model Builds an embedding model
    register_provider_type register_provider_type(...) provider metadata None Adds a new provider to the registry
    get_provider_type_registry get_provider_type_registry() none registry Lists and resolves available providers
    get_vector_store get_vector_store(...) backend config store interface Resolves the configured vector backend

    Use cases¶

    Retrieval-augmented workflow¶

    from msflib.ai_core.providers import get_llm

llm = get_llm(settings)
response = llm.invoke("Summarize the latest product notes for customer support.")
print(response)

    Vector-based search¶

    from msflib.ai_core.providers import get_embeddings

embeddings = get_embeddings(settings)
vector = embeddings.embed_query("How do I reset my workspace password?")

    Configuration and environment variables¶

    Typical values include:

    • AI_CORE__LLM_PROVIDER
    • AI_CORE__LLM_MODEL
    • AI_CORE__LLM_API_KEY
    • AI_CORE__EMBEDDING_PROVIDER
    • AI_CORE__EMBEDDING_MODEL
    • AI_CORE__EMBEDDING_API_KEY

    Troubleshooting¶

    • Missing provider packages raise actionable import errors telling you which extra to install.
    • Unsupported embedding and LLM provider combinations fail fast during validation.
    • Vector store backend mismatches usually mean the configured backend is not installed or not initialized.
