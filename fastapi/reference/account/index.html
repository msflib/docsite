    msflib.account.contracts ¶

    Structural contracts (Protocols) exported by msflib.account.

    These are lightweight interfaces that other modules can use to type-hint optional dependencies on account-adjacent concepts (e.g. workspaces) without requiring a hard package dependency on the module that owns the concrete model.

    UserContract ¶

    Bases: Protocol

    Structural contract for user objects.

    id, account_id, and workspace_id are required; any concrete user model that exposes these attributes satisfies this contract.

    WorkspaceContract ¶

    Bases: Protocol

    Structural contract for workspace objects.

    Only id is required; any concrete workspace model that exposes an id attribute satisfies this contract.

    workspace ¶

    Workspace integration contract.

    Any workspace object passed into a router or action that does not want to declare a hard dependency on msflib-workspaces should type-hint against this Protocol.

    The concrete workspace model in msflib.workspaces satisfies this protocol structurally; no explicit inheritance is required.

    WorkspaceContract ¶

    Bases: Protocol

    Structural contract for workspace objects.

    Only id is required; any concrete workspace model that exposes an id attribute satisfies this contract.

    UserContract ¶

    Bases: Protocol

    Structural contract for user objects.
