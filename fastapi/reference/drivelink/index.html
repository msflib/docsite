    msflib.drivelink.documents_contract ¶

    Integration contract for a future msflib-documents module (RAG, etc.).

    Stable identity for ingested files

    • Use (drivelink_id, node_id, version) where node_id is a DrivelinkNode row with kind == file. drivelink_id partitions document identities across logical drivelink roots. Bump version when file bytes are replaced.

    Event bus (emitted by ModelAction lifecycle hooks on DrivelinkNode; see msflib.actions.ModelAction):

    • drivelinknode-create-pre-commit
    • drivelinknode-update-pre-commit
    • drivelinknode-delete-pre-commit

    Listeners receive (model, {"session": session, ...}) as for other SQLModel entities.

    Out of scope here

    • Embeddings, chunking, and retrieval logic live in msflib-documents, not in drivelink.
