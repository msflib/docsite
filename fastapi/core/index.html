    Core Module¶

    The core package is the foundation for the entire MSFLib FastAPI monorepo. It provides configuration, database, security, event bus, policy, scope, and shared helper services that the feature modules build on.

    What it provides¶

    • Namespace-aware settings and tiered config resolution
    • Database session helpers and model conventions
    • Password and JWT utilities
    • Event bus and hook registration patterns
    • Scope model for tenant/workspace/account awareness
    • Shared action and API helpers for modules

    Installation¶

    [tool.poetry.dependencies]
python = ">=3.10,<4.0"
msflib = { git = "https://github.com/msflib/fastapi.git", subdirectory = "core", rev = "dev" }

    Core concepts¶

    Settings and config¶

    The core package uses SettingsBase and ModuleSettingsBase to provide layered, namespace-aware configuration. Resolution typically follows:

    default -> environment -> tenant -> workspace -> user -> request override

    This is especially important for modules like workspace_config, ai_core, and downstream integrations that need scoped behavior.

    Policy layer¶

    msflib.policy provides a consistent policy envelope and resolution service to resolve settings in a traceable way across scopes.

    from msflib.policy import InMemoryPolicyDecisionLogger, PolicyResolutionService

    Scope model¶

    The scope package gives request-scoped context for tenant, workspace, and account identities.

    from msflib.scope import get_scope_dependencies

    Event bus¶

    The event bus supports app-scoped emitters and listener registration so modules can react to lifecycle changes without hard-coded coupling.

    from msflib.eventbus import bind_app_emitter

    Example configuration¶

    from msflib.core.config import SettingsBase

class AppSettings(SettingsBase):
    SECRET_KEY: str
    DATABASE_URL: str

settings = AppSettings()

    Then pull module-scoped settings using the .scope(...) pattern.

    settings.scope("AUTH")
settings.scope("ACCOUNT")

    Public API surface¶

    Name Signature Params Returns Description
    SettingsBase SettingsBase environment config settings object Base app config with namespaced access
    ModuleSettingsBase ModuleSettingsBase module defaults settings class Base config for feature modules
    bind_app_emitter bind_app_emitter(app) app instance AppEmitter Bind one emitter to an app instance
    PolicyResolutionService PolicyResolutionService(...) scoped store, logger service Resolve policy settings with trace records
    get_scope_dependencies get_scope_dependencies(...) identity callables dependency namespace Build scoped auth dependencies

    Typical usage¶

    from fastapi import FastAPI
from msflib.eventbus import bind_app_emitter
from msflib.scope import get_scope_dependencies

app = FastAPI()
emitter = bind_app_emitter(app)

scope_deps = get_scope_dependencies(
    get_current_account=get_current_account,
    get_current_workspace=get_current_workspace,
)
