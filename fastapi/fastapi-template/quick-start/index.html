    Quick start¶

    Get the template running locally on SQLite, with no PostgreSQL or Redis. For the full setup, see Getting started.

    Prerequisites¶

    • Python 3.10 to 3.13. Python 3.14 is not supported yet: the pinned sqlmodel release fails to import on it.
    • Poetry.
    • Git, with access to github.com/msflib/fastapi (Poetry installs MSFLib from there).

    Steps¶

    # 1. Get the code
git clone https://github.com/msflib/fastapi-template.git my-api
cd my-api

# 2. Install dependencies
poetry install

# 3. Configure: copy the example env and switch to SQLite
cp .env-example .env
sed -i.bak 's/^USE_SQLITE=false/USE_SQLITE=true/' .env

# 4. Create the tables, the first superuser and the default workspace
poetry run python -m app.initial_data

# 5. Start the dev server
poetry run uvicorn app.main:app --reload

    If your default python3 is 3.14, point Poetry at a supported interpreter before step 2, for example poetry env use python3.12.

    The template has no Alembic revisions yet, so there are no migrations to run. Step 4 creates the tables from the model metadata on an empty database. See Database and seeding before running it against a database that already holds data.

    Check it works¶

    There is no dedicated health endpoint. Use the API docs and a login instead:

    What Where
    Swagger UI http://localhost:8000/docs
    OpenAPI schema http://localhost:8000/api/v1/openapi.json

    Log in as the superuser from .env (FIRST_SUPERUSER / FIRST_SUPERUSER_PASSWORD) and call /me:

    TOKEN=$(curl -s -X POST http://localhost:8000/api/v1/login \
  -d 'username=admin@example.com&password=xxxxxxxxxxxx' \
  | python3 -c 'import json,sys; print(json.load(sys.stdin)["access_token"])')

curl -s http://localhost:8000/api/v1/me -H "Authorization: Bearer $TOKEN"

    Change SECRET_KEY and FIRST_SUPERUSER_PASSWORD in .env before you deploy anywhere. Every variable is described in Configuration.

    Project structure¶

    app/
├── main.py             FastAPI app: CORS, /api/v1 router, static uploads mount
├── bootstrap.py        Registers module event hooks at startup
├── core/config.py      AppSettings: combines the MSFLib settings classes, read from .env
├── api/
│   ├── deps.py         Session, key store and current-account dependencies
│   └── api_v1/
│       ├── api.py      Mounts the auth, account, profile and admin routers
│       └── endpoints/  Your own routers (admin/ holds the admin accounts router)
├── actions/            One action (service) instance per model
├── models/             Re-exports the MSFLib models; add your own here
├── db/                 Engine/session (session.py) and first-run data (init_db.py)
├── initial_data.py     Entry point for step 4
├── seed/               Seeders, sample CSV data and the seed CLI (run_seeder.sh)
├── worker.py           Celery app (in-memory broker unless REDIS_HOST is set)
├── email-templates/    MJML sources and built HTML emails
└── tests/              Pytest suite

    eventbus/, schemas/ and services/ are empty packages where your own code goes. How the app is wired explains each file in detail.
