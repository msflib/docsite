    MSFLib FastAPI Documentation¶

    MSFLib FastAPI is a modular backend framework built around a shared core package and a family of independently installable modules. The monorepo is designed for teams that want a secure, scoped, and extensible FastAPI foundation without forcing every application to adopt every feature.

    This documentation focuses on the public packages shipped in this repository and the patterns used to integrate them into a host application.

    Repository structure¶

    The core repo is organized around a shared runtime and optional feature modules:

    • core/ — shared configuration, security, event bus, database, scope, and policy primitives
    • modules/account — account and profile lifecycle
    • modules/auth — auth, JWT tokens, password reset, Google OAuth
    • modules/ai_core — LLM, embeddings, vector store, and agent/tool plumbing
    • modules/ai_api — user-facing AI endpoints and transport adapters
    • modules/documents — upload, extraction, ingestion, and indexing flow
    • modules/workspaces — workspace lifecycle and workspace-aware profile access
    • modules/workspace_config — tenant/workspace/user tiered config storage
    • modules/notifications — in-app and broadcast notifications
    • modules/workspace_notifications — workspace-scoped notification flows
    • modules/ingestion — shared job queue and ingestion execution pipeline
    • modules/knowledge — knowledge graph and retrieval-oriented domain model

    Recommended installation pattern¶

    Use Poetry and install only the modules your app needs.

    [tool.poetry.dependencies]
python = ">=3.10,<4.0"
msflib = { git = "https://github.com/msflib/fastapi.git", subdirectory = "core", rev = "dev" }
msflib-account = { git = "https://github.com/msflib/fastapi.git", subdirectory = "modules/account", rev = "dev" }
msflib-auth = { git = "https://github.com/msflib/fastapi.git", subdirectory = "modules/auth", rev = "dev" }
msflib-workspaces = { git = "https://github.com/msflib/fastapi.git", subdirectory = "modules/workspaces", rev = "dev" }

    Quick start¶

    from fastapi import FastAPI

from msflib.auth.router import router as auth_router
from msflib.account.router import account_router, profile_router
from msflib.workspaces.router import router as workspaces_router

app = FastAPI()

app.include_router(auth_router(prefix="/auth"))
app.include_router(account_router(prefix="/account"))
app.include_router(profile_router(prefix="/profiles"))
app.include_router(workspaces_router(prefix="/workspaces"))

    Typical application flow¶

    Most projects follow a layered setup:

    1. Install msflib core.
    2. Add account and auth to manage identity.
    3. Add workspaces and workspace_config for organization and scoped settings.
    4. Add ai_core and ai_api when building AI features.
    5. Add documents, ingestion, and knowledge when implementing retrieval pipelines.
    6. Wire in notifications or workspace_notifications for product events and user messaging.

    Development notes¶

    • Settings are organized with namespace-scoped configuration and tier precedence.
    • Core features are shared across modules via SettingsBase, ModuleSettingsBase, and scoped config resolution.
    • Authentication and workspace-based authorization rely on dependency factories rather than one-off route logic.
    • The repo favors modular installation, not a single monolithic server package.
