    Notifications Module¶

    The Notifications module provides account-level notifications and admin broadcast workflows, with support for in-app delivery and optional channel dispatch such as email and SMS.

    What it provides¶

    • In-app account notifications
    • Admin broadcast notifications
    • Channel dispatching by notification type and channel
    • Notification and account-notification actions

    Installation¶

    [tool.poetry.dependencies]
msflib = { git = "https://github.com/msflib/fastapi.git", subdirectory = "core", rev = "dev" }
msflib-notifications = { git = "https://github.com/msflib/fastapi.git", subdirectory = "modules/notifications", rev = "dev" }

    Optional extras:

    poetry add msflib-notifications[email]
poetry add msflib-notifications[sms]
poetry add msflib-notifications[all]

    Router wiring¶

    from fastapi import FastAPI
from msflib.notifications.router import (
    account_notification_router,
    admin_account_notification_router,
)

app = FastAPI()

app.include_router(
    account_notification_router(
        get_session=get_session,
        get_current_account=get_current_account,
        prefix="/notifications",
    )
)

app.include_router(
    admin_account_notification_router(
        get_session=get_session,
        get_current_account=get_current_account,
        role_check=role_check,
        settings=settings,
        prefix="/admin/notifications",
    )
)

    Public API surface¶

    Name Signature Params Returns Description
    account_notification_router account_notification_router(...) session, account dep router User-facing notification endpoints
    admin_account_notification_router admin_account_notification_router(...) session, role check, settings router Admin broadcast and management endpoints
    dispatch_account_notifications dispatch_account_notifications(...) session, settings, data, sender, receivers notification output Sends notifications through configured channels
    NotificationAction NotificationAction[...] settings action instance Notification lifecycle actions

    Example: dispatch a welcome notification¶

    from msflib.notifications.models import NotificationCreate, NotificationType, NotificationChannel
from msflib.notifications.service.notification import dispatch_account_notifications

notification = dispatch_account_notifications(
    session=session,
    settings=settings,
    data=NotificationCreate(
        title="Welcome",
        message="Welcome to the platform",
        channels=[NotificationChannel.inapp, NotificationChannel.email],
    ),
    n_type=NotificationType.admin,
    sender=current_admin,
    receivers=receivers,
)

    Routes¶

    Account routes¶

    • GET /notifications — list notifications
    • GET /notifications/{notification_id} — fetch one notification
    • PATCH /notifications/{notification_id}/mark — mark read/unread
    • PATCH /notifications/mark-all — mark all read/unread
    • DELETE /notifications/{notification_id} — delete one

    Admin routes¶

    • POST /admin/notifications — send admin notification
    • GET /admin/notifications/all — list sent notifications
    • GET /admin/notifications/{notification_id} — fetch one sent notification
    • DELETE /admin/notifications/{notification_id} — delete one sent notification

    Channels¶

    Supported channels include inapp, email, sms, with enum values for push and discord as well.

    Troubleshooting¶

    • If email or SMS channels are not working, verify the downstream email or SMS configuration and credentials.
    • If no notifications appear, confirm the notifier is passed a valid receiver list.
    • If admin routes fail, ensure the correct role check is mounted and the current account is recognized as admin.
