Modular product platform

Build once. Ship across every product layer.

MSFLib is a modular foundation for teams building modern applications with shared backend infrastructure, secure access control, workspace primitives, and a growing set of cross-platform product modules. It helps teams standardize the building blocks they reuse across multiple apps without sacrificing flexibility.

from msflib.core.config import CoreSettings
from msflib.auth.config import AuthSettings
from msflib.account.config import AccountSettings

class AppSettings(WorkspaceSettings, AccountSettings, AuthSettings, CoreSettings):
    SECRET_KEY: str = "your-secret"
    ACCESS_TOKEN_EXPIRE_MINUTES: int = 60 * 24 * 8

settings = AppSettings()
