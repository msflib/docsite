    Theme¶

    The kh_theme package defines the design system for the monorepo. It is the primary package for color tokens, typography, spacing, borders, and assembled ThemeData objects used across the other packages.

    Package purpose¶

    kh_theme provides:

    • a default seed-based brand palette
    • semantic colors for success, warning, and info states
    • a Material type scale and spacing model
    • a theme extension for app-specific semantic values
    • ready-to-use KhTheme.light() and KhTheme.dark() builders

    Status¶

    This package is available and is the standard styling layer for kh_ui and kh_screens.

    Installation¶

    dependencies:
  kh_theme:
    git:
      url: https://github.com/msflib/flutter.git
      path: packages/kh_theme

    Basic usage¶

    import 'package:flutter/material.dart';
import 'package:kh_theme/kh_theme.dart';

MaterialApp(
  theme: KhTheme.light(),
  darkTheme: KhTheme.dark(),
  home: const Scaffold(
    body: Center(
      child: Text('Hello from kh_theme'),
    ),
  ),
);

    You can also supply a custom seed color:

    MaterialApp(
  theme: KhTheme.light(seedColor: Colors.teal),
  darkTheme: KhTheme.dark(seedColor: Colors.teal),
);

    Token categories¶

    kh_theme intentionally separates the structural tokens from the brand seed:

    final spacing = KhSpacing.md;
final radius = KhRadius.md;
final elevation = KhElevation.level2;
final accent = KhColors.brandSeed;

    The app can adjust the seed color while keeping the rest of the design system stable and coherent.

    Semantic colors¶

    The theme extension exposes semantic values that Material's default color scheme does not cover well:

    final theme = Theme.of(context).extension<KhThemeExtension>();
final successColor = theme?.success ?? Colors.green;

    This is useful when you need consistent appearance for validation, success, info, and warning states in app interfaces.

    Typography¶

    KhTypography defines the design-system type scale, which is applied through the assembled ThemeData:

    final title = KhTypography.headlineMedium;
final label = KhTypography.labelLarge;

    The default font is the local Inter asset included with the package, unless the consuming app overrides it at theme creation time.

    Best practices¶

    • Prefer theme-driven styling over hard-coded colors in widget code.
    • Use Theme.of(context) and KhThemeExtension to read semantic values.
    • Keep customizations at the app boundary, not inside every individual widget.
